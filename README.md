# Moonemail documentation

Public documentation for [Moonemail](https://moonemail.co), hosted at [docs.moonemail.co](https://docs.moonemail.co) using Mintlify Starter.

This repository is a publishing mirror. Documentation and the OpenAPI contract are maintained together in the application source; generated files should not be edited here. API responses and SDKs share the same contract.

The live API playground is disabled. Preview with `npx mint@4.2.1157 dev`; validate with `npx mint@4.2.1157 validate`.

Support: support@moonemail.co
