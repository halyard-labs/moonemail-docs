Use the [official SDK repository](https://github.com/halyard-labs/moonemail-sdks)
for server-side integrations. All three clients cover sending, receiving,
inboxes, domains and health, webhooks, suppressions, API keys and permissions.

The SDKs are MIT licensed and generated from the same public OpenAPI contract as
this reference. Dashboard billing and OAuth consent are not API-key operations.

<Note>
JavaScript/TypeScript is available on [npm](https://www.npmjs.com/package/moonemail).
Python is available as a GitHub Release wheel while PyPI setup is completed.
Go uses a versioned module tag. Pin versions and test upgrades.
</Note>

<Tabs>
<Tab title="JavaScript / TypeScript">
```bash
npm install moonemail@0.1.0
```

```typescript
import { Moonemail } from 'moonemail';

const email = new Moonemail(process.env.MOONEMAIL_API_KEY!);
const sent = await email.emails.send({
  from: 'Acme <hello@your-verified-domain.com>',
  to: ['recipient@example.com'],
  subject: 'Your receipt',
  text: 'Thanks for your order.',
}, { idempotencyKey: 'order-123-receipt' });
```

Node.js 22+. [TypeScript usage and errors](https://github.com/halyard-labs/moonemail-sdks/tree/main/typescript).
</Tab>
<Tab title="Python">
```bash
pip install https://github.com/halyard-labs/moonemail-sdks/releases/download/v0.1.0/moonemail-0.1.0-py3-none-any.whl
```

```python
import os
from moonemail import Moonemail

with Moonemail(os.environ['MOONEMAIL_API_KEY']) as email:
    sent = email.emails.send({
        'from': 'Acme <hello@your-verified-domain.com>',
        'to': ['recipient@example.com'],
        'subject': 'Your receipt',
        'text': 'Thanks for your order.',
    }, idempotency_key='order-123-receipt')
```

Python 3.10+. [Python usage and errors](https://github.com/halyard-labs/moonemail-sdks/tree/main/python).

Keep keys on your server. Clients do not automatically retry sends; reuse the
same idempotency key and payload when retrying, and respect rate-limit responses.
These clients do not add unsupported features such as campaigns or SMTP.

## Versions and updates

SDK releases track the deployed API contract version. The release workflow
regenerates and tests all three clients before publishing. See
[release notes](https://github.com/halyard-labs/moonemail-sdks/releases) for changes
and [the public contract](https://github.com/halyard-labs/moonemail-sdks/blob/main/spec/openapi.json)
for the schemas behind the clients. Your installed package stays pinned until you
choose to upgrade.
