Moonemail is Australian owned and operated. Email content and delivery records are stored and processed in Sydney. Recipient mailboxes and services you connect may be overseas.

Start with a [verified domain and your first send](/quickstart), or explore the **API reference** for request fields, permissions and response schemas.

## What you can build

- **Transactional sending:** receipts, password resets, account alerts and welcome messages.
- **Receiving:** generated inbox addresses, message retrieval, attachments and signed events.
- **Operations:** domain verification, delivery timelines, webhook destinations and suppressions.
- **Agent integrations:** a remote MCP server with OAuth and explicit permissions.

Access is currently invite-only. [Request access](mailto:support@moonemail.co) or [open your dashboard](https://app.moonemail.co).

Campaigns, hosted templates, SMTP relay and custom receiving domains are not available. The receiving API is for applications; it is not a human shared mailbox.

## One contract

This reference is generated from the same request and permission contract used by the API and MCP tools, with response schemas checked against the service's wire representations. Download the [OpenAPI specification](/openapi.json).

Examples are copyable but do not execute requests from this site. Keep API keys in your application's secret store.
